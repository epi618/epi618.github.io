1 Bypass Paywalls Clean

1.1 付费墙

首先我们应该了解什么是付费墙。付费墙就是以访问限制来要求读者订阅付费的一种手段。以新闻业和学术论文为最盛。但是对于轻度阅读者而言，付费墙其实很不友好。对于重度阅读者而言，您其实应该付费。关于付费墙的存在至今仍然存在着争议

1.2 Bypass Paywalls Clean

接下来，我使用magnolia1234开发的Bypass Paywalls Clean来绕过付费墙。Bypass Paywalls Clean是一款自由开源的浏览器插件，其主要支持 Mozilla Firefox和Google Chrome。由于违反Google的规则。Bypass Paywalls Clean没有在Chrome商店上架，因为违反了DMCA规则， 也没有上架Firefox的插件商店。目前该项目托管在GitFlic。

1.3 Bypass Paywalls Clean for Chrome MS Edge or Brave

首先从GitFlic网站下载 zip-file
接着解压 bypass-paywalls-chrome-clean-master
其次在地址栏输入chrome://extensions，进入扩展插件页面
接着打开开发者模式
最后找到bypass-paywalls-chrome-clean-master文件夹，在扩展插件界面选择打开该文件夹即可

1.4 Bypass Paywalls Clean for Firefox

首先从GitFlic网站下载xpi-file
然后直接拖拽刚才下载的文件进入Firefox即可。

1.5 后续

一旦安装完成后，我们便可以轻松浏览很多网站的文章。有关于技术的、新闻的、财经的、政治的各种网站。还有不同语言的网站。你可以自行去查看，支持绕过哪些付费墙网站。

当然以上的操作是在Windows平台完成，当然也支持Android平台和ios平台。欢迎和我交流。

2 uBlock Origin

如果很讨厌那些广告，尤其是国内的网站平台，各种广告满天飞，牛皮癬一样。当然也有应对措施，那就是uBlock Origin。uBlock Origin是 一款高效且性能强大的插件，其能安装在Chrome和Firefox系列的浏览器。uBlock Origin能屏蔽广告、网页跟踪、网页弹窗、和恶意网站。其 内置了很多相关的列表，包括 EasyList, EasyPrivacy, Peter Lowe’s Blocklist, Online Malicious URL Blocklist, and uBO filter lists.

3 SponsorBlock

在播放Youtube视频的时候，中间突然跳出的广告，很让人扫兴。这个时候，SponsorBlock就大有用途了。SponsorBlock会自动跳过视频中 的广告。
